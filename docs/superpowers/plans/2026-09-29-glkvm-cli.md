# glkvm CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Go CLI, `glkvm`, that drives arwen (GL.iNet Comet X, PiKVM kvmd 4.82 fork) over its HTTP API: status, screenshot, host port switching, EDID profiles, keyboard, mouse, action batches, virtual drive (MSD), doctor.

**Architecture:** `internal/kvmd` is a typed HTTP client for the kvmd API, one file per API area. `internal/kvmdfake` is an in-process fake kvmd built on `httptest` that every unit test uses. Pure logic lives in `internal/edid`, `internal/keys`, `internal/coords`. `internal/cli` holds cobra commands that call the client and render text or JSON. No test in this plan touches the real device; live verification is done by the controller after each task.

**Tech Stack:** Go 1.27, `github.com/spf13/cobra`, stdlib only otherwise (`net/http`, `image/jpeg`, `image/png`, `encoding/json`). Built and tested in the `golang:1.27.0` container via `./dev`.

**Spec:** `docs/REQUIREMENTS.md`

## Global Constraints

* Go module path `github.com/txomon/glinet-pikvm-cli`, binary `cmd/glkvm`.
* `CGO_ENABLED=0`, one static binary. No Python anywhere.
* Never build or run Go on the host. Every go command runs through `./dev go ...`.
* Only dependency beyond stdlib: `github.com/spf13/cobra`.
* Credentials never on the command line and never in the repo. Config file `~/.config/glkvm/config.json` (override path with `GLKVM_CONFIG`), password override with `GLKVM_PASSWORD`.
* Auth headers on every request: `X-KVMD-User`, `X-KVMD-Passwd`.
* Any non-2xx response or `"ok": false` body is an error carrying kvmd's `error` and `error_msg`. Never swallow errors, never retry input actions.
* Port switch and EDID flash confirm by reading state back.
* Exit codes: 0 ok, 1 device or API error, 2 usage error, 3 config error.
* `--output text|json` on every command. JSON envelope: `{"ok":true,"result":...}` or `{"ok":false,"error":{"kind":"...","message":"..."}}`.
* Subagents must not contact arwen (`arwen.example.net`, `192.0.2.10`, `198.51.100.18`). All tests use `internal/kvmdfake`.
* Commit after each task with a short lowercase message in the repo's style, no attribution lines.

## Review Focus

* Screenshot while capture is invalid (`source.online` false, or `real_resolution` starting `invalid_resolution:`): expect exit 1 and a message naming the reason, never an empty or stale file. Test in Task 7.
* Port given as `0`, `5`, `1.3` or `abc`: expect exit 2 with "port must be 1 to 4"; never send a bare integer `port=` to kvmd (bare integers are 0-based indexes on the device). Test in Task 7.
* EDID hex with whitespace, uppercase, 128 bytes, bad checksum, or a mode failing the gsv1127x rules: expect normalization for the first three, and a refusal (exit 2) for the last two unless `--force`. Test in Tasks 3 and 8.
* Mouse coordinates outside the current capture resolution, or no capture signal to scale against: expect exit 2 or 1 with a clear message, not a clamped click somewhere else. Test in Task 9.
* Config file missing, unreadable, or mode wider than 0600: missing and unreadable exit 3; wider mode prints a warning to stderr and continues. Test in Task 1.

## Verified API facts (read before any task)

All paths are under `<device url>/api`. Responses are `{"ok": bool, "result": ...}`. Errors look like `{"ok": false, "result": {"error": "ValidatorError", "error_msg": "..."}}`.

* `GET /info` → `result.meta`, `result.system`, `result.extras` (auth check endpoint).
* `GET /upgrade/version` → `{"ok":true,"result":{"model":"RM4PE","version":"V1.10.1 release3"}}`.
* `GET /switch` → `result.summary = {"active_id":"1.4","active_port":3,"synced":true}`, `result.model.ports = [{"channel":0,"id":"1.1","name":"",...}, ... "1.4"]`, `result.video.links = [true,true,true,true]`, `result.usb_otg.links = [false,true,true,true]`.
* `POST /switch/set_active?port=1.N` selects host port N (1 to 4). A bare integer `port=K` is a 0-based index (`port=3` selects `1.4`), so always send `1.N`. `POST /switch/set_active_next`, `/switch/set_active_prev`. Returns `{"ok":true,"result":{}}`. Capture follows within 1 s.
* `GET /streamer` → `result.streamer.source = {"online":true,"real_resolution":"1200x752@60","resolution":{"width":1200,"height":752},"captured_fps":60}`; `result.streamer.hdmi.signal` bool. With a rejected mode, `real_resolution` reads `invalid_resolution:WxH@F`.
* `GET /streamer/snapshot` → `image/jpeg` body. Query `allow_offline=0` by default. A JSON error body when there is no signal.
* `GET /upgrade/get_edid` → `{"ok":true,"result":{"edid":"00ffffff..."}}` (lowercase hex, 512 chars).
* `GET /upgrade/edid_list` → a bare JSON array (no envelope): `[{"key":"E2560x1440","label":"2560x1440/GLKVM/60Hz","content":"00ff...","audio":true,"hz":60,"is_default":true}, ...]`. Keys present: `E2560x1440`, `E3840x2160`, `E1920x1080AOC`, `E1920x1080`, `E1920x1200`, and more.
* `POST /upgrade/edid` with form body `edid=<hex>` (`application/x-www-form-urlencoded`), 256 or 512 hex chars. Success: `{"ok":true,"result":{"status":"success","message":"EDID data has been written and applied"}}`. Failure: HTTP 400 with an error message.
* `GET /hid` → `result.online`, `result.connected`, `result.keyboard.online`, `result.mouse.online`, `result.mouse.absolute`.
* `POST /hid/events/send_key?key=<WebName>` press and release; add `&state=true|false` for press or release only.
* `POST /hid/events/send_shortcut?keys=ControlLeft,AltLeft,Delete`.
* `POST /hid/print?limit=0&keymap=en-us` with the text as the raw body. `limit=0` disables the 1024 char cap. `slow=true` adds 20 ms between keys.
* `POST /hid/events/send_mouse_move?to_x=<int>&to_y=<int>`, absolute range -32768 to 32767.
* `POST /hid/events/send_mouse_button?button=left|right|middle|up|down[&state=true|false]`.
* `POST /hid/events/send_mouse_wheel?delta_x=<int>&delta_y=<int>`, and `/hid/events/send_mouse_relative?delta_x=&delta_y=`, each delta -127 to 127.
* `GET /msd` → `result.enabled`, `result.online`, `result.busy`, `result.drive = {"cdrom":true,"connected":false,"image":null,"rw":false}`, `result.storage.images = {"name.iso": {"size":..,"complete":true,...}}`, `result.storage.parts[""].free`.
* `POST /msd/write?image=<name>` with the raw file as body and a real `Content-Length`. `POST /msd/set_params?image=<name>&cdrom=1|0&rw=0|1`. `POST /msd/set_connected?connected=1|0`. `POST /msd/remove?image=<name>`.

Key names for `send_key` and `send_shortcut` are the keys of `WEB_TO_EVDEV` in `../reference/kvmd/kvmd/keyboard/mappings.py` (`KeyA`..`KeyZ`, `Digit0`..`Digit9`, `F1`..`F24`, `ControlLeft`, `ShiftLeft`, `AltLeft`, `MetaLeft`, `Enter`, `Escape`, `Backspace`, `Tab`, `Space`, `Delete`, `ArrowUp`, ...). Extract the full list with:

```sh
command grep -oE '^    "[A-Za-z0-9]+": ecodes' ../reference/kvmd/kvmd/keyboard/mappings.py | cut -d'"' -f2
```

```go
package config

import (
	"encoding/json"
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"sort"
)

var ErrConfig = errors.New("config")

type Device struct {
	Name        string `json:"-"`
	URL         string `json:"url"`
	User        string `json:"user"`
	Password    string `json:"password"`
	InsecureTLS bool   `json:"insecure_tls"`
}

type File struct {
	Devices       map[string]Device `json:"devices"`
	DefaultDevice string            `json:"default_device"`
}

func DefaultPath() string {
	if p := os.Getenv("GLKVM_CONFIG"); p != "" {
		return p
	}
	home, err := os.UserHomeDir()
	if err != nil {
		return ".config/glkvm/config.json"
	}
	return filepath.Join(home, ".config", "glkvm", "config.json")
}

func Load(path string) (*File, error) {
	b, err := os.ReadFile(path)
	if err != nil {
		return nil, fmt.Errorf("%w: read %s: %v", ErrConfig, path, err)
	}
	var f File
	if err := json.Unmarshal(b, &f); err != nil {
		return nil, fmt.Errorf("%w: parse %s: %v", ErrConfig, path, err)
	}
	return &f, nil
}

func (f *File) Names() []string {
	names := make([]string, 0, len(f.Devices))
	for n := range f.Devices {
		names = append(names, n)
	}
	sort.Strings(names)
	return names
}

func (f *File) Device(name string) (Device, error) {
	if name == "" {
		name = f.DefaultDevice
	}
	if name == "" {
		return Device{}, fmt.Errorf("%w: no device given and no default_device set", ErrConfig)
	}
	d, ok := f.Devices[name]
	if !ok {
		return Device{}, fmt.Errorf("%w: unknown device %q (configured: %v)", ErrConfig, name, f.Names())
	}
	if d.URL == "" {
		return Device{}, fmt.Errorf("%w: device %q has no url", ErrConfig, name)
	}
	d.Name = name
	if p := os.Getenv("GLKVM_PASSWORD"); p != "" {
		d.Password = p
	}
	return d, nil
}

func PermWarning(path string) string {
	st, err := os.Stat(path)
	if err != nil {
		return ""
	}
	if st.Mode().Perm()&0o077 != 0 {
		return fmt.Sprintf("warning: %s is mode %o and holds a password; chmod 600 it", path, st.Mode().Perm())
	}
	return ""
}
```

`output.go`:

```go
package cli

import (
	"encoding/json"
	"errors"
	"fmt"
	"io"

	"github.com/txomon/glinet-pikvm-cli/internal/config"
)

const (
	ExitOK     = 0
	ExitDevice = 1
	ExitUsage  = 2
	ExitConfig = 3
)

type UsageError struct{ Msg string }

func (e UsageError) Error() string { return e.Msg }

func usagef(format string, a ...any) error { return UsageError{Msg: fmt.Sprintf(format, a...)} }

func render(w io.Writer, format string, result any, text func(io.Writer)) error {
	if format == "json" {
		enc := json.NewEncoder(w)
		enc.SetIndent("", "  ")
		return enc.Encode(map[string]any{"ok": true, "result": result})
	}
	if text != nil {
		text(w)
	}
	return nil
}

func classify(err error) (string, int) {
	var ue UsageError
	switch {
	case errors.As(err, &ue):
		return "usage", ExitUsage
	case errors.Is(err, config.ErrConfig):
		return "config", ExitConfig
	default:
		return "device", ExitDevice
	}
}

func renderError(w io.Writer, format string, err error) int {
	kind, code := classify(err)
	if format == "json" {
		enc := json.NewEncoder(w)
		enc.SetIndent("", "  ")
		_ = enc.Encode(map[string]any{"ok": false, "error": map[string]string{"kind": kind, "message": err.Error()}})
		return code
	}
	fmt.Fprintf(w, "glkvm: %s\n", err)
	return code
}
```

`root.go`: a `globals` struct `{device, output, configPath string; timeout time.Duration}`; `newRoot(g *globals, stdout, stderr io.Writer) *cobra.Command` with persistent flags `-d/--device`, `-o/--output` (default `text`, validated to `text|json`), `--config` (default `config.DefaultPath()`), `--timeout` (default `15s`), `SilenceUsage: true`, `SilenceErrors: true`. A `version` subcommand printing `glkvm dev`. `Execute(args, stdout, stderr)` builds the root, sets args, runs, and on error calls `renderError`, writing JSON errors to stdout and text errors to stderr. Cobra's own flag and arg errors become `UsageError` by wrapping them in `SetFlagErrorFunc` and by using `Args` validators that return `UsageError`. JSON results go to stdout; warnings go to stderr.

The fake enforces auth (wrong headers → 403 with `{"ok":false,"result":{"error":"ForbiddenError","error_msg":"Forbidden"}}`), implements every endpoint in "Verified API facts" with the documented shapes, records every call, and mirrors device semantics: `set_active?port=1.N` sets `ActivePort=N-1`; a bare integer `port=K` sets `ActivePort=K` (0-based) so tests can catch misuse.
